About & limitations

  • Rules-based evidence viewer. No AI, no wallet, no sign-up, no tracking.
  • Three fixed tokens with hand-curated source quotes. It does not read arbitrary websites.
  • “Differs” means the numbers are different. The cause is not checked and it is not an accusation.
  • No full-access keys does not prove a contract is unchangeable. A code hash identifies code; it does not verify it.
  • Live mode uses the free public RPC, which can be slow, rate-limited or refused by some file viewers.
  • The download hash proves the file was not edited after export, not that any claim is true. Not financial advice.
