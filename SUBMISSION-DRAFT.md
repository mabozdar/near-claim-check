Project name: NEAR Claim Check — Evidence Inspector

Description (about 600 characters, the limit is 20–2,000):
A rules-based, read-only evidence inspector for NEAR tokens. For REF, USDC and USDt it shows the project's own documented claim next to NEAR mainnet data pinned to one block: exact total supply (BigInt), access keys (full-access means the code can be redeployed; no keys does not prove immutability), and the code hash (identity, not verification). Differences are labelled "differs, cause not verified", never as scam verdicts. Live public RPC reads have progress, cancel and timeout; a cached snapshot works offline; evidence bundles are SHA-256 hashed and can be checked in the app. No AI, no wallet, no cost.
