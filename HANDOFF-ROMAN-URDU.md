# Aap ko kya karna hai (step by step)
1. **File save karo:** `NEAR-Claim-Check-Final.html` phone ya computer par rakho. Chrome mein kholo (file manager ke preview mein nahi).
2. **Snapshot dekho:** REF khud khulega. Block number, supply aur "differs" dekho. USDC aur USDt ke cards bhi tap karo.
3. **Live test:** "Live public RPC" chuno aur ek card tap karo. Steps 1 se 5 chalenge. Agar error aaye (rate limit/network) to "Retry" dabao. Purana data kabhi chupke se nahi dikhega.
4. **Evidence:** "Download evidence bundle" dabao, phir neeche "Check a downloaded evidence file" mein wahi file do. "✓ Intact" aana chahiye.
5. **Video:** 60–90 second ki screen recording apni awaaz ke saath banao (`DEMO-SCRIPT.md` dekho).
6. **Repo:** GitHub par apna public repo banao aur is ZIP ki saari files daalo (README aur LICENSE pehle se maujood hain). Ye kaam aap khud karoge; hum ne kuch upload nahi kiya.
7. **X post:** `X-POST-DRAFT.txt` ko dekh kar apne account se post karo, video ke saath, @NEARProtocol aur #NEARHackathon tag karke.
8. **Form:** `SUBMISSION-DRAFT.md` se details bharo. Repo link aur post link dono zaroori hain. Aakhri waqt: **Sunday 15 Nov, subah 4:59 PKT**. Submit sirf ek dafa, check karke.
Yaad rakho: jeetne ki guarantee nahi. Country/KYC ke rules official site par likhe nahi hain. Koi paisa kharch nahi hota.
